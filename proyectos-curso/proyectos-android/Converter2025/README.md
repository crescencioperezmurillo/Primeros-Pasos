# Converter2025 – Conversor de Euros a Rupias

## Descripción general

Converter2025 es una aplicación de conversión monetaria desarrollada en el contexto del curso de Programación de Aplicaciones para Dispositivos Móviles. Su finalidad es permitir al usuario realizar conversiones de cantidades expresadas en euros (€) a rupias (₹), mediante la aplicación de un tipo de cambio fijo previamente establecido en el código de la aplicación.

El proyecto constituye un ejercicio práctico de desarrollo de aplicaciones móviles, orientado a implementar una herramienta sencilla y funcional que permita introducir una cantidad monetaria, procesar el valor introducido y obtener su equivalencia en la moneda de destino.

## Funcionalidad principal

La aplicación permite introducir una cantidad en euros y calcular automáticamente su valor equivalente en rupias, utilizando un factor de conversión constante.

A diferencia de los conversores conectados a servicios financieros o fuentes de cotización en tiempo real, Converter2025 utiliza una tasa de conversión fija. Por tanto, los resultados obtenidos dependen exclusivamente del valor establecido durante el desarrollo de la aplicación y no se actualizan según las fluctuaciones del mercado de divisas.

## Objetivos del proyecto

- Desarrollar una aplicación móvil con una finalidad práctica y concreta.
- Implementar operaciones matemáticas para la conversión de unidades monetarias.
- Gestionar la introducción y el procesamiento de datos proporcionados por el usuario.
- Presentar los resultados de forma clara y comprensible.
- Aplicar los conocimientos adquiridos durante la formación en programación de aplicaciones móviles.

## Características técnicas

El proyecto implementa un sistema de conversión basado en un tipo de cambio predefinido, mediante el cual se obtiene la equivalencia entre euros y rupias.

La aplicación está concebida como una herramienta de conversión básica, con un funcionamiento independiente de servicios externos de cotización monetaria.

## Contexto formativo

Este desarrollo forma parte de los trabajos prácticos realizados durante el curso de Programación de Aplicaciones para Dispositivos Móviles y representa un ejercicio de aplicación de los fundamentos de programación, el tratamiento de datos de entrada y la implementación de operaciones dentro de una aplicación móvil.
