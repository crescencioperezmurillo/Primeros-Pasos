# Conversor de Euros a Rupias

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación móvil nativa para Android, diseñada para realizar conversiones de cantidades monetarias de euros (€) a rupias mediante la aplicación de un factor de conversión fijo. Su finalidad principal es proporcionar una herramienta sencilla y accesible que permita calcular equivalencias monetarias de forma rápida, facilitando la consulta de cantidades expresadas en ambas divisas.

La aplicación permite introducir una cantidad determinada en euros y obtener automáticamente su equivalencia en rupias a partir del valor de conversión establecido. Este procedimiento se basa en una operación matemática directa, utilizando un coeficiente previamente definido que determina la relación entre ambas unidades monetarias.

Desde el punto de vista funcional, el proyecto se centra en la implementación de una interfaz de usuario sencilla, orientada a facilitar la introducción de cantidades y la presentación de los resultados obtenidos. La aplicación busca ofrecer una experiencia de utilización intuitiva, reduciendo los elementos innecesarios y priorizando la claridad en el proceso de conversión.

Desde el punto de vista del desarrollo tecnológico, la aplicación ha sido programada específicamente para el sistema operativo Android, empleando las herramientas y tecnologías propias de su entorno de desarrollo. Su implementación permite trabajar con la construcción de interfaces móviles, la gestión de datos introducidos por el usuario y la aplicación de operaciones aritméticas para obtener resultados dinámicos.

El proyecto constituye una práctica de desarrollo de aplicaciones móviles centrada en la creación de una utilidad funcional, permitiendo aplicar conocimientos de programación, diseño de interfaces y tratamiento de datos en un caso de uso concreto.

## Objetivos del proyecto

- Desarrollar una aplicación móvil nativa para el sistema operativo Android.
- Implementar un conversor monetario entre euros y rupias.
- Aplicar un factor de conversión fijo para calcular las equivalencias entre ambas divisas.
- Permitir la introducción de cantidades monetarias mediante una interfaz sencilla.
- Realizar operaciones aritméticas y mostrar los resultados de forma inmediata.
- Diseñar una interfaz intuitiva que facilite la utilización de la herramienta.
- Aplicar conocimientos de programación, gestión de datos y desarrollo de interfaces móviles.
- Comprender el funcionamiento de una aplicación basada en la introducción de datos, el procesamiento de información y la presentación de resultados.

- **Lenguaje de programación:** empleado para implementar la lógica de conversión y el funcionamiento de la aplicación.

## Funcionamiento de la aplicación

El funcionamiento de la aplicación se fundamenta en la conversión directa de cantidades monetarias mediante un coeficiente fijo previamente establecido.

El usuario introduce una cantidad expresada en euros y la aplicación realiza el cálculo correspondiente, multiplicando el importe por el factor de conversión definido. El resultado se presenta en rupias, permitiendo conocer rápidamente la equivalencia monetaria de la cantidad introducida.

Este sistema permite realizar conversiones de manera sencilla sin necesidad de consultar servicios externos ni utilizar una conexión a internet para obtener el resultado. No obstante, al emplear un factor fijo, los valores calculados no representan necesariamente el tipo de cambio vigente en los mercados financieros.

## Ámbito de aplicación

La aplicación se sitúa en el ámbito de las herramientas digitales de cálculo y conversión monetaria. Su planteamiento combina una operación matemática básica con el desarrollo de una interfaz móvil, dando lugar a una utilidad práctica orientada a facilitar la consulta de equivalencias entre dos divisas.

Aunque su funcionalidad es específica y limitada, constituye un ejemplo de aplicación móvil en la que se integran la entrada de datos, el procesamiento de información y la presentación dinámica de resultados.
