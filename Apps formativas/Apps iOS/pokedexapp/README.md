# Pokédex – Aplicación de consulta de Pokémon

## Proyecto personal de desarrollo de una aplicación para iOS inspirada en la Pokédex

### Presentación

Este repositorio contiene el desarrollo de un proyecto personal consistente en la creación de una **aplicación para dispositivos iOS destinada a la consulta, identificación y exploración de información sobre los Pokémon**, tomando como referencia el concepto y la funcionalidad de una Pokédex.

La aplicación permite seleccionar diferentes Pokémon y consultar sus principales características y propiedades mediante una interfaz gráfica organizada y de fácil navegación. Su planteamiento se centra en ofrecer una experiencia de consulta visual e intuitiva, presentando la información individualizada de cada criatura.

Entre los datos disponibles se encuentran aspectos como el nombre, número de identificación, imagen, categoría, tipos, altura, peso, características físicas y estadísticas básicas. De esta manera, la aplicación reúne en un mismo entorno información relevante para la identificación y consulta de las distintas especies.

El proyecto se ha desarrollado como una iniciativa personal de aprendizaje y aplicación práctica de conocimientos relacionados con el desarrollo de software para el ecosistema iOS.

### Estado actual del proyecto

**La aplicación se encuentra terminada y dispone de funcionalidades operativas.** Este repositorio contiene el código fuente del proyecto y constituye un registro del trabajo realizado durante su planificación, desarrollo e implementación.

La aplicación permite acceder a la información de los diferentes Pokémon disponibles, seleccionar especies concretas y consultar sus correspondientes fichas descriptivas. Su estructura y sus componentes se encuentran implementados para ofrecer una experiencia de consulta funcional.

Aunque el desarrollo inicial está finalizado, el proyecto podrá recibir futuras actualizaciones, mejoras de diseño o ampliaciones de contenido en función de las necesidades que se identifiquen.

### Objetivos del proyecto

El objetivo principal ha sido desarrollar una aplicación para iOS que permita consultar información sobre diferentes Pokémon mediante una interfaz inspirada en las enciclopedias digitales y dispositivos de identificación del universo Pokémon.

Entre los principales objetivos se encuentran:

- Crear una interfaz visual inspirada en el concepto tradicional de una Pokédex.
- Permitir la exploración y selección de diferentes Pokémon.
- Mostrar información individualizada mediante fichas descriptivas.
- Incorporar imágenes y recursos visuales para facilitar su identificación.
- Presentar sus principales propiedades físicas, incluyendo altura y peso.
- Mostrar información relativa a sus tipos y características particulares.
- Incorporar estadísticas básicas de cada especie.
- Organizar la información de manera estructurada para facilitar su consulta.
- Aplicar conocimientos de programación y desarrollo de interfaces para dispositivos iOS.

### Contenido y organización

La aplicación se estructura en torno a un catálogo de Pokémon organizado mediante fichas individuales, desde las cuales se puede acceder a la información correspondiente a cada especie.

Cada ficha reúne los principales datos identificativos y descriptivos del Pokémon seleccionado, ofreciendo una presentación clara y diferenciada de sus características.

Entre los contenidos disponibles se encuentran:

- **Identificación:** nombre, número de Pokédex, imagen representativa y categoría.
- **Características físicas:** altura, peso y descripción de sus particularidades.
- **Tipología:** tipo o combinación de tipos a los que pertenece cada Pokémon.
- **Estadísticas:** valores correspondientes a sus atributos básicos, como puntos de salud, ataque, defensa, ataque especial, defensa especial y velocidad.
- **Habilidades:** información sobre las habilidades características de cada especie.
- **Información complementaria:** otros datos descriptivos que permiten ampliar el conocimiento de los Pokémon.

### Tecnologías y herramientas

El desarrollo de la aplicación se ha realizado utilizando tecnologías orientadas al ecosistema de dispositivos Apple, complementadas con archivos JSON para la estructuración y consulta de los datos correspondientes a los diferentes Pokémon.

Entre las herramientas y tecnologías empleadas se encuentran:

- **iOS:** plataforma de destino de la aplicación.
- **Swift:** lenguaje de programación utilizado para implementar la lógica y los diferentes componentes.
- **SwiftUI:** tecnología empleada para la construcción de la interfaz gráfica.
- **JSON (JavaScript Object Notation):** formato utilizado para organizar y estructurar los datos de los Pokémon, facilitando su almacenamiento, lectura y procesamiento dentro de la aplicación.
- **Xcode:** entorno de desarrollo utilizado para la programación, compilación, depuración y pruebas.
- **Git:** herramienta de control de versiones.
- **GitHub:** plataforma utilizada para alojar el código fuente y documentar el proyecto.

### Gestión y organización de datos

La aplicación utiliza archivos JSON para almacenar y organizar la información asociada a los diferentes Pokémon. Este formato permite estructurar los datos mediante pares clave-valor y facilitar su posterior lectura y procesamiento desde la aplicación.

Esta solución permite mantener separada la información de las especies respecto a los componentes de la interfaz y la lógica de funcionamiento, favoreciendo una organización más clara del proyecto y facilitando la incorporación, modificación y ampliación de los registros.

Los datos estructurados pueden incluir información identificativa, características físicas, tipologías, estadísticas y otros atributos específicos de cada Pokémon.

La utilización de este formato también permite trabajar con estructuras de información organizadas, que pueden ser interpretadas y utilizadas por la aplicación para generar dinámicamente las fichas correspondientes a cada especie.

### Metodología y enfoque de desarrollo

El desarrollo se ha basado en la construcción de una aplicación organizada en diferentes componentes, prestando especial atención a la presentación de la información, la estructuración de los datos y la experiencia de navegación.

Se ha trabajado en la organización de los registros de cada Pokémon mediante archivos JSON y en su integración con los elementos visuales de la aplicación. Este planteamiento permite mantener una separación entre los datos, la lógica de funcionamiento y los componentes de la interfaz.

Asimismo, el diseño de la interfaz toma como referencia el concepto de la Pokédex, adaptándolo a una experiencia de usuario propia de los dispositivos iOS.

La implementación de estos elementos permite ofrecer un sistema de consulta organizado, en el que la información de cada especie se presenta de forma individualizada y coherente.

### Finalidad y proyección del proyecto

Además de su finalidad como aplicación de consulta, este proyecto constituye una muestra práctica de los conocimientos y habilidades aplicados al desarrollo de software para dispositivos móviles.

Su publicación en GitHub permite conservar el código fuente, documentar las tecnologías utilizadas y mostrar el resultado final de un proyecto desarrollado de manera independiente.

La aplicación representa una experiencia práctica en el diseño de interfaces, la organización y estructuración de datos mediante archivos JSON, la lectura y procesamiento de información y la implementación de funcionalidades mediante tecnologías propias del ecosistema iOS.

**Este repositorio contiene una versión funcional y terminada del proyecto, susceptible de recibir futuras mejoras, actualizaciones y ampliaciones.**
