# Aplicación de Recetas de Cocina

## Proyecto personal de desarrollo de una aplicación interactiva de recetas para iOS

### Presentación

Este repositorio contiene el desarrollo de un proyecto personal orientado a la creación de una **aplicación para dispositivos iOS destinada a la consulta, organización y elaboración guiada de recetas de cocina**.

La aplicación está concebida como una herramienta interactiva que permite explorar diferentes recetas, consultar sus ingredientes y seguir de manera ordenada las instrucciones necesarias para su preparación. Su planteamiento busca ofrecer una experiencia de uso intuitiva y práctica, facilitando el acceso a la información culinaria y acompañando al usuario durante las distintas fases de elaboración de cada plato.

Una de sus principales características es la posibilidad de seguir las recetas mediante un sistema de pasos secuenciales, que permite consultar las instrucciones de preparación de forma progresiva. De esta manera, el usuario puede avanzar por las diferentes etapas de una receta, mantener un seguimiento de las tareas realizadas y consultar las indicaciones correspondientes a cada momento de la elaboración.

La aplicación reúne en un mismo entorno diferentes elementos relacionados con la preparación culinaria, como la descripción de los platos, los ingredientes necesarios, las cantidades y los procedimientos de elaboración.

El proyecto se ha desarrollado como una iniciativa personal de aprendizaje y aplicación práctica de conocimientos relacionados con el diseño y desarrollo de aplicaciones para el ecosistema iOS.

### Estado actual del proyecto

**La aplicación se encuentra terminada y dispone de funcionalidades operativas.** Este repositorio contiene el código fuente del proyecto y constituye un registro del trabajo realizado durante su planificación, desarrollo e implementación.

La aplicación permite consultar las recetas disponibles, acceder a su información y seguir las instrucciones de preparación mediante una secuencia organizada de pasos. Su funcionamiento está orientado a facilitar la comprensión del procedimiento culinario y permitir que el usuario consulte las indicaciones conforme avanza en la elaboración de cada plato.

### Objetivos del proyecto

El objetivo principal ha sido desarrollar una aplicación para iOS que facilite la consulta y elaboración de recetas mediante un sistema de instrucciones organizadas y seguimiento progresivo.

Entre los principales objetivos se encuentran:

- Crear una aplicación que permita consultar diferentes recetas de cocina.
- Organizar la información culinaria de forma clara y estructurada.
- Mostrar los ingredientes necesarios y sus correspondientes cantidades.
- Incorporar instrucciones detalladas para la elaboración de cada receta.
- Implementar un sistema de navegación secuencial entre los diferentes pasos de preparación.
- Facilitar el seguimiento del procedimiento mediante la consulta progresiva de las instrucciones.
- Diseñar una interfaz gráfica intuitiva y adaptada a dispositivos iOS.
- Mejorar la experiencia de uso durante la preparación de los platos.
- Aplicar conocimientos de programación, diseño de interfaces y organización de información mediante el desarrollo de una aplicación móvil funcional.

### Contenido y organización

La aplicación se estructura en torno a un catálogo de recetas, desde el cual el usuario puede seleccionar diferentes elaboraciones y acceder a su correspondiente información.

Cada receta dispone de una estructura propia que permite consultar los datos necesarios para comprender y realizar su preparación. La información se presenta de manera organizada, diferenciando los ingredientes del procedimiento de elaboración.

Entre los principales contenidos contemplados se encuentran:

- **Identificación de la receta:** nombre del plato, imagen representativa y descripción general.
- **Ingredientes:** relación de los productos necesarios para la elaboración de cada receta.
- **Cantidades:** indicación de las proporciones y cantidades correspondientes a los ingredientes.
- **Preparación:** descripción del procedimiento necesario para elaborar el plato.
- **Pasos de elaboración:** instrucciones distribuidas en diferentes etapas que permiten seguir la receta de forma secuencial.
- **Información complementaria:** datos adicionales relacionados con la preparación y las características de cada elaboración.

Esta organización permite separar la información general de las recetas de las instrucciones específicas de preparación, facilitando su consulta y seguimiento.

### Sistema de seguimiento de recetas

Uno de los elementos principales de la aplicación es su sistema de seguimiento de instrucciones, concebido para acompañar al usuario durante la elaboración de cada receta.

En lugar de presentar todo el procedimiento como un único bloque de texto, las instrucciones se organizan en pasos individuales que pueden consultarse progresivamente. Este planteamiento permite centrar la atención en la tarea que corresponde realizar en cada momento y facilita la comprensión del proceso completo.

El sistema permite avanzar por las diferentes etapas de preparación, consultar las indicaciones correspondientes y mantener una secuencia ordenada de elaboración.

Este enfoque convierte la aplicación en algo más que un catálogo de recetas, proporcionando una herramienta interactiva que acompaña al usuario durante el proceso culinario.

### Tecnologías y herramientas

El desarrollo de la aplicación se ha realizado utilizando tecnologías orientadas al ecosistema de dispositivos Apple.

Entre las herramientas y tecnologías empleadas se encuentran:

- **iOS:** plataforma de destino de la aplicación.
- **Swift:** lenguaje de programación utilizado para implementar la lógica y los diferentes componentes.
- **SwiftUI:** tecnología empleada para la construcción de la interfaz gráfica y los elementos interactivos.
- **JSON (JavaScript Object Notation):** formato para la estructuración y organización de información, cuando se utiliza como fuente de datos de las recetas.
- **Xcode:** entorno de desarrollo utilizado para la programación, compilación, depuración y pruebas.
- **Git:** herramienta de control de versiones para registrar las modificaciones realizadas durante el desarrollo.
- **GitHub:** plataforma utilizada para alojar el código fuente y documentar el proyecto.

### Gestión y organización de la información

La aplicación requiere una organización estructurada de los datos correspondientes a las recetas, permitiendo mantener diferenciados los elementos informativos y las instrucciones de preparación.

La información de cada elaboración puede organizarse mediante registros que contengan su identificación, descripción, ingredientes, cantidades y secuencia de pasos. Esta estructura facilita la consulta de los contenidos y su presentación dentro de los diferentes componentes de la interfaz.

La separación entre los datos y los elementos visuales permite mantener una organización más clara del proyecto y facilita la incorporación de nuevas recetas o la modificación de las existentes.

### Metodología y enfoque de desarrollo

El desarrollo se ha basado en la construcción de una aplicación organizada en diferentes componentes, prestando especial atención a la experiencia de usuario, la presentación de la información y la interacción durante el proceso de preparación.

Se ha trabajado en la estructuración de los contenidos culinarios y en su integración con los elementos visuales y funcionales de la aplicación. Asimismo, se ha prestado especial atención al sistema de navegación entre instrucciones, con el objetivo de ofrecer una experiencia de seguimiento sencilla y coherente.

El diseño busca adaptar la consulta tradicional de recetas a un formato interactivo, en el que el usuario pueda acceder a la información necesaria y avanzar por las diferentes fases de elaboración sin perder la secuencia del procedimiento.
